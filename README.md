# 🎗️ Breast Cancer Prediction System

A Machine Learning-based web application that predicts whether a breast tumor is **Benign** or **Malignant** using clinical diagnostic features. The application provides fast and accurate predictions through a simple and user-friendly web interface.

## 📌 Project Overview

The Breast Cancer Prediction System helps users analyze medical diagnostic data and predict the likelihood of breast cancer. The model is trained using machine learning techniques and deployed as an interactive web application.

> **Note:** This project is developed for educational and research purposes only. It is **not** a replacement for professional medical diagnosis.

---

## ✨ Features

* 🔍 Predicts Breast Cancer (Benign / Malignant)
* 🤖 Machine Learning-based prediction

## 📊 Input Parameters

The prediction model uses several medical diagnostic measurements, including:

* Radius Mean
* Texture Mean
* Perimeter Mean
* Area Mean
* Smoothness Mean
* Compactness Mean
* Concavity Mean
* Concave Points Mean
* Symmetry Mean
* Fractal Dimension Mean

---

## 🎯 Output

The system predicts one of the following:

* ✅ **Benign**
* ⚠️ **Malignant**

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/lakshay-12092006
```

Go to the project directory:

```bash
cd Breast-Cancer-Prediction
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```
